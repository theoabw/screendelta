Measuring rules, fixed in specs/001-frame-delta-engine/plan.md before the first
measurement:

- GOMAXPROCS=1, because the latency requirement is stated for one CPU core.
- Percentiles, never a mean alone.
- Memory sampled every 1,000 frames over a 10,000 frame stream, with a GC before
  each sample so the figure describes what is retained rather than what is queued.
- Every number quoted in README.md is regenerated from committed output.
