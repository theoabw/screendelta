Memory and allocation measurement, 2026-09-26.
Commands: make memcheck, and the allocation guard in the same package.

memory ceiling, 10,000 frames at 1920x1080:
  wall clock        2.558 s
  peak heap         25,200,496 bytes  (24.0 MiB)
  peak system       38,979,864 bytes  (37.2 MiB)
  engine buffers    16,588,800 bytes  (two 1920x1080 rgba8 buffers)
  heap at frame 1000   25,200,496 bytes
  heap at frame 10000  25,200,496 bytes

allocation steady state, 320x240, two consecutive windows of 1,000 frames:
  first window   8,220 bytes per frame
  second window  8,220 bytes per frame
  pixel buffers allocated by the engine: 2

Requirements this measures:
  NFR-003  at most 128 MB over 10,000 frames, no growth with stream length
           met with room to spare: 24.0 MiB peak against a 128 MiB ceiling, and the heap
           is identical at frame 1,000 and frame 10,000
  SC-003   10,000 frame stream within the memory ceiling with no identifier reuse
           met for the memory half; identifier reuse is measured separately

What this does not measure: latency and throughput. Those are the diff package's
benchmarks, which do not exist yet, so NFR-001, NFR-002 and SC-002 remain unmeasured.
